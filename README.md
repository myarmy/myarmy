## Featured projects / Öne çıkan projeler

### [Nexvo APRS](https://github.com/myarmy/nexvo-aprs)

A non-commercial, open-source Android and server platform for amateur-radio communications.

- APRS-IS station reception, map display, callsign search and APRS messaging
- Android phones and tablets; Turkish and English interface support
- Position beacon configuration, APRS.fi integration and optional queued/offline messaging
- iOS, macOS and Windows designs are in progress

Amatör telsiz haberleşmesi için ticari olmayan, açık kaynak Android ve sunucu platformu. Android telefon/tablet desteği ile Türkçe ve İngilizce arayüz sunar; iOS, macOS ve Windows tasarımları devam etmektedir.

### RotaVan

A free, community-benefit navigation project. It includes APRS.fi-based live tracking for amateur radio operators who enter their callsign and profile details.

Toplum yararına, ücretsiz navigasyon projesi; amatör telsiz kullanıcıları için çağrı işareti ve profil bilgileri ile APRS.fi tabanlı canlı takip içerir.

### Solar Pro

Android tools for estimating solar-panel system cost and power needs.

Solar panel sistemleri için maliyet ve güç hesabını kolaylaştıran Android araçları.
